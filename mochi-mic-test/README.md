# Отдельная проверка INMP441

Этот самостоятельный проект не использует Wi-Fi, OLED, кнопку, эмоции и порог срабатывания. Он измеряет оба канала I2S и выводит полные 24-битные отсчёты и RMS в Monitor. Ненулевые данные сами по себе не доказывают исправность: уровень должен изменяться в ответ на звук.

## Подключение

Отключите USB и прочие источники питания. Отсоедините OLED и сенсорную кнопку, включая их питание, и оставьте только микрофон:

| INMP441 | ESP32-C3 SuperMini |
|---|---|
| VDD | 3,3 В (не 5 В) |
| GND | GND |
| L/R | GND |
| SD | GPIO4 |
| WS | GPIO5 |
| SCK | GPIO6 |

Нужен надёжный контакт: вставленные без пайки провода могут не соединяться с площадками. Следуйте подписям на модуле, а не его ориентации на фотографии. Производитель предусматривает подтяжку SD к земле 100 кОм: если её нет на модуле, добавьте резистор SD–GND. Включена также внутренняя подтяжка GPIO4.

Если сильный нагрев платы ещё не устранён, не подавайте питание. Изоляция периферии и эта прошивка не подтверждают безопасность повреждённой платы.

## Запуск после проверки питания и проводки

1. Откройте в VS Code папку `E:\Projects\ESP32\mochi-mic-test`.
2. Выполните PlatformIO Build, затем Upload. Это временно заменит прошивку робота на плате; исходники робота и файловая система сохраняются. Upload Filesystem Image не нужен.
3. Откройте Monitor, 115200. Если начало пропущено, нажмите RST.
4. Сравните 3–5 секунд тишины и речи рядом с микрофоном, затем хлопните на некотором расстоянии. Не стучите по микрофону.

Логи раз в секунду:

```text
Frames: ... | read: ESP_OK
L: RMS24=... | min=... max=... | nonzero=...
R: RMS24=... | min=... max=... | nonzero=...
```

- `Frames` около 16000 за секунду: чтение идёт с ожидаемой частотой.
- При L/R=GND сигнал ожидается слева. Сравните, растёт ли L RMS24 при речи. Справа могут быть нули или остаточные данные.
- `ZERO DATA`: оба канала целиком нулевые; проверяйте питание, общую землю, SD/WS/SCK и пайку. Это ещё не доказательство поломки микрофона.
- `NO SAMPLES`: чтение не получает данные; важен код ошибки в строке `read`.
- RMS24 — условные единицы, не дБ и не RMS из основной прошивки: здесь используется полная разрядность.

Для возврата откройте `E:\Projects\ESP32\mochi-oled` и выполните Upload основной прошивки.
